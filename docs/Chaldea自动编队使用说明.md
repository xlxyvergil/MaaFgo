# Chaldea 自动编队使用说明

“Chaldea 自动编队”会读取 Chaldea 的队伍数据，在 FGO 编队页还原本地从者、当前已选助战的位置，以及本地从者的概念礼装。本说明同时适用于独立的“Chaldea 自动编队”任务，以及其他战斗流程中“是否使用 Chaldea 队伍”开关所自动调用的编队阶段。

## 适用入口

- **独立任务**：手动选好助战并进入编队页后，运行“Chaldea 自动编队”，只还原并确认队伍。
- **战斗流程内编队**：在日常战斗、活动、冠位戴冠战或直接战斗等任务中选择“原生自动战斗”，再开启“是否使用 Chaldea 队伍”。可通过“编队方式”选择只检查当前队伍，或自动还原完整编队；成功后继续进入战斗。

## 功能边界

- 会调整从者与助战位置；开启“自动编成礼装”后，会尝试为普通本地从者装备 Chaldea 指定礼装。
- 编队阶段对 Chaldea 数据标记为冠位的从者或助战只核对从者本人，不核对、拆卸或编成其礼装；使用当前冠位助战替代 Chaldea 本地从者时也遵循同一规则。冠位礼装由游戏预设，即使分享数据记录了 `equip1`、`equip2` 或 `equip3`，编队阶段也将它们视为已满足。选择“使用 Chaldea 配置”助战方式时，助战列表筛选会另外核对第 1/2 格中有记录且具备模板的礼装。
- 当大量从者不匹配时，自动编队会优先尝试“编队解散”再重建；冠位从者所在队伍不支持解散，如果“编队编辑”或“编队解散”点击后限定时间内没有进入下一步，任务会跳过解散，改从“配置变更”进入逐槽换位和替换，不会因此直接失败或误点“开始任务”。
- 不会从助战列表选择助战，不会修改魔术礼装、从者等级或技能等级。
- 独立任务仅完成并确认编队，不会点击“开始任务”进入战斗。
- 不能按等级或技能等级区分同名从者。保留多个同名从者时，请先把不想使用的低练度个体放入保管室。

## 运行前准备

1. 确保游戏画面为横屏 `16:9`，推荐分辨率为 `1280 × 720`，并确认 MaaFgo 已连接正确的游戏资源包。
2. 准备 Chaldea 分享链接、队伍 ID、关卡 ID、本地队伍 JSON，或已下载的缓存文件名之一。
3. 确认攻略中的本地从者和礼装确实由当前账号持有，并预先选择好攻略要求的助战。
4. 不要在运行期间点击、滚动或切换游戏画面。

> 自动编队会安全校验助战身份。Chaldea 已指定助战但当前助战不匹配时，任务会停止，不会继续进入战斗。

## 独立任务：只还原队伍

适合已经手动进入“编队确认”或“配置变更”页面，只希望把当前队伍改成 Chaldea 攻略配置的场景。

1. 在 MaaFgo 中选择“Chaldea 自动编队”。
2. 在“Chaldea 队伍导入”中填写分享链接、队伍 ID、关卡 ID、JSON 文件，或缓存名称。
3. 按需要配置下列选项：

   - “自动编成礼装”：默认开启；若只想调整从者与助战位置，可关闭。
   - “满破礼装缺失时”：仅在开启“自动编成礼装”后显示；默认改查非满破版本，也可选择跳过该礼装。
   - “是否用助战代替编队数据”：仅当分享数据没有标记助战时使用；当前助战必须与攻略中的一个本地从者相同。
   - “自动补齐从者和羁绊礼装”：首次使用建议保持关闭，先确认基础自动编队成功。

4. 在游戏中先选好助战，进入编队确认页或点击“配置变更”进入编辑页。
5. 启动任务并等待完成。任务会复核从者、助战和已启用的礼装设置，再确认编队。

## 原生自动战斗：编队后继续战斗

适合刷本时自动应用 Chaldea 队伍。

1. 选择需要的刷本任务，并将战斗方式设为“原生自动战斗”。
2. 开启“是否使用 Chaldea 队伍”。
3. 填写“Chaldea 队伍导入”，再选择“编队方式”：

   - “手动”（默认）：只核对从者身份和位置，不选人、不配礼装，也不执行羁绊补齐。Chaldea 指定的从者都已存在但位置不同时，会自动换位、复核并保存；缺少目标从者时会输出当前与目标信息并停止任务。Chaldea 未指定位置中的其他本地从者会保留。
   - “自动”：按导入数据还原队伍，并显示礼装、助战替代和羁绊补齐选项。

4. 正常启动任务。流程会依次完成关卡导航、助战选择、编队检查或自动编队、点击开始任务，再进入原生自动战斗。

“助战方式”可选“首个助战”“自定义助战”或“使用 Chaldea 配置”。选择后者时，必须同时开启“是否使用 Chaldea 队伍”并填写有效的导入来源；任务会读取队伍中明确标记的唯一助战，按从者、职介、等级、宝具、技能，以及已指定的普通礼装或冠位第 1/2 格礼装筛选。未开启导入、来源为空或无效、未标记助战或标记多位助战、指定礼装缺少名称/图像资源时都会停止，不会改选首个助战。Chaldea 未提供的可选筛选数据不作为条件；冠位第 3 格礼装暂不按 ID 校验。选择另外两种助战方式时，编队模块仍不会代替助战选择。

手动方式下，Chaldea 明确指定助战时仍会校验助战身份；未指定助战时，当前助战只能占用 Chaldea 未使用的空位。手动方式不支持用助战替代 Chaldea 中的本地从者。

## 可选：羁绊补齐

开启“自动补齐从者和羁绊礼装”后，基础编队完成时会以 Chaldea 已指定的位置和助战为保护对象，在剩余位置按 COST 尝试补齐本地从者与常驻羁绊礼装。

- “补齐从者优先星级”只决定候选搜索优先级，仍会受 COST 限制。
- “自动记忆”默认开启。完整优化成功后会保存当前编队；相同 Chaldea 队伍和羁绊设置再次运行且阵容完全一致时，只检查额外从者的羁绊状态，不再重复扫描和重编。
- “自动修改其他位置从者/礼装”开启时，Chaldea 未指定但已被旧队伍占用的位置可以被替换；关闭时会保留原内容。
- “羁绊基础值”用于比较固定值和百分比羁绊礼装，通常保持默认值即可。
- 编辑礼装时若游戏弹出冠位礼装窗口，任务会关闭弹窗并跳过该槽的普通礼装编成。对于本地冠位从者，任务会识别弹窗区域内已有的 0～3 张羁绊礼装并纳入后续羁绊规划；冠位助战及其全部礼装始终忽略，不参与识别、计分或匹配。

羁绊补齐首次运行会扫描仓库，可能需要数分钟。可先运行“构建个人从者礼装库”，再开启“使用本地从者库”和“使用本地礼装库”以加速。召唤、出售从者或礼装、改变礼装满破状态后，应重新构建本地库。

自动记忆命中后，任务仍会检查 Chaldea 未指定位置上的额外从者。发现羁绊已满时，允许更换从者会重新执行优化；不允许更换则保留当前编队、输出 warning 日志并继续战斗。队伍位置、礼装、羁绊选项或戴冠战职介发生变化时，旧记忆不会命中。记忆文件损坏或无法写入只会关闭本次加速，不影响正常战斗。

## 常见问题

### 为什么任务停止，没有进入战斗？

常见原因是当前助战与攻略指定助战不一致、目标从者或礼装未持有、目标图片资源缺失，或同名从者导致识别到错误个体。任务在这些情况下会停止，避免错误编队后继续战斗。

### Chaldea 没有标记助战怎么办？

默认会保留当前助战，并把它移动到 Chaldea 未使用的空位置；若没有空位置会失败。只有当前助战与攻略中的某个本地从者相同时，才可开启“是否用助战代替编队数据”。

### 指定礼装没有装备成功怎么办？

先确认“自动编成礼装”已开启、礼装由当前账号持有且工程包含其识图资源。攻略要求满破而仓库只有未满破版本时，按“满破礼装缺失时”的配置处理；普通助战礼装不会被修改，冠位从者和冠位助战的礼装配置则默认视为满足。

### 本地库存文件有什么用？

它只为羁绊补齐加速，不是基础自动编队的前置条件。文件缺失、损坏或扫描未完成时，任务会回退到实时扫描。构建流程见[个人从者与礼装库构建说明](个人从者礼装库构建说明.md)。

## 使用建议

首次使用时，先关闭羁绊补齐与礼装自动编成，仅验证从者和助战是否能正确还原；成功后再逐步开启礼装和羁绊补齐。遇到失败时保留日志和错误截图，并记录使用的 Chaldea 链接、当前助战及选项配置，便于排查。
