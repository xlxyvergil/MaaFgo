# 自动幕间副本

## 目标与使用

在国服打开“幕间物语”或日服打开“幕間の物語”列表后启动“自动幕间副本”。任务从列表顶部查找已开启的幕间，跳过置灰条目；支持直接进入助战和先“前往故事的舞台”两条路径。同一个幕间有后续进度时继续挑战，地图型幕间完成后通过左侧“前往幕间物语”返回总列表，再查找下一项。

“挑战次数上限”允许1至999，默认999。每完成一个小关进度计一次，包含纯剧情；进入地图、重试和战败不计次数。达到上限后停在当前列表或地图；确认列表内只有未开启条目时可提前结束。一个幕间有多少段由现场剩余条目决定，不按固定场数推定完成。真实列表完全为空但没有可确认的空态文字时，保守停止，不声称已经清空。

复用原生战斗的助战、编辑器/Chaldea队伍、高级策略、跳过剧情、茶壶和羁绊满停止。吃苹果沿用基础选项，默认金苹果，可切换“不食用”或其他类型。“自动处理编队限制情况”默认开启：限制关沿用游戏编队和默认战斗逻辑，下一小关恢复用户配置；关闭后遇到限制会保留现场停止。关闭“跳过剧情”时尊重正常剧情播放；需要手动推进的剧情、未适配的强制选择或等待超时会保留画面停止。

## 导航和识别

- 总列表以右上“幕间物语”前景标题及左上“关闭”共同确认。奖励、剧情和限制弹窗优先于背景列表。
- 对右侧棕色卡片逐行读取，联合卡片亮度、任务文字及锁定条件判断可挑战状态，不凭“新！”或位置判断。临时“开放条件缓和中”文字不能误判为未开启；暗棕色无字候选判为不确定。
- 地图只接受同一卡片内的Interlude和AP，拒绝绿色自由关卡及已完成行。地图没有主线NEXT标记，不能直接套用主线定位器。英文标记另有小范围OCR，容忍国服字距造成的拆分。
- 固定滑动、点击和等待放在Pipeline。总列表最多400次、地图列表最多12次单步复位/扫描，每步重拍，触底后再复核稳定帧；找不到候选不等于已完成。地图只有正向确认Free/完成/锁定证据且没有不确定行时才能判定当前页无目标，外层仍须复位遍历。
- 只有确认战后返回地图/列表或纯剧情完成后才计数。未知画面、定位失败和超时停止并保留现场，不执行通用回主界面恢复。

## 实现入口

`agent/custom/interlude_action.py`中的`InterludeRunner`复用主线单场战斗、助战及限制编队处理，导航与计数独立；`interlude_recognition.py`负责逐行候选及状态报告。固定动作与识别参数在`assets/resource/base/pipeline/自动幕间副本.json`，任务和选项在`assets/tasks/自动幕间副本.json`、`assets/options/自动幕间副本.json`。已接入interface与Agent注册，不更改自动推主线的选项。

非显然实机约束也写在相关Pipeline的`doc`：列表触顶650ms仍存在25至64px弹性回弹，等待2400ms后再检测稳定；棕色地图背景可能与卡片色带粘连，须先定位亮色卡头；地图返回按钮须有前景白底，避免奖励遮罩后的背景文字误命中。内联OCR均有全局唯一`sub_name`。

## 回归与边界

国服实现提交时，静态OCR检查、Schema（base Pipeline、interface、任务和选项）通过。该提交全量单元测试2135项通过（其中5项跳过）；新增幕间调度/配置28项、识别单元14项、真实MaaFramework识别组件6项通过。图像回归覆盖混排灰行、直接AP、AP0、临时黄字、地图背景粘连、Free排除、奖励遮罩、未知空图和暗棕无字；状态回归覆盖计数、上限、地图交接、未知界面、AP不足不食用及限制状态逐关恢复。

限制编队本轮没有自然实机样本，依据复用主线及相关回归验证；未实机穷尽所有幕间、长列表终点和其他分辨率。日服识别补充见下节。所有正式改动只在开发目录，未同步打包版，未修改打包版version。
