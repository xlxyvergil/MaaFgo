# 自动幕间副本

## 目标与使用

在国服打开“幕间物语”或日服打开“幕間の物語”列表后启动“自动幕间副本”。任务从列表顶部查找已开启的幕间，跳过置灰条目；支持直接进入助战和先“前往故事的舞台”两条路径。同一个幕间有后续进度时继续挑战，地图型幕间完成后通过左侧“前往幕间物语”返回总列表，再查找下一项。地图没有该返回入口时，确认地图已扫描完后回主界面，经“迦勒底之门 → 幕间物语”重新进入总列表。

也可从故事舞台启动，或先手动选择幕间小关，停在助战选择、编队确认页后启动。任务会接管当前小关，使用原有助战、队伍和战斗选项；结算确认返回幕间列表或故事舞台后再自动选关。当前小关同样计入挑战次数上限。助战和编队页无法确认所选副本类型，请先自行选择幕间关卡。

“挑战次数上限”允许1至999，默认999。每完成一个小关进度计一次，包含纯剧情；进入地图、重试和战败不计次数。达到上限后停在当前列表或地图；确认列表内只有未开启条目时可提前结束。一个幕间有多少段由现场剩余条目决定，不按固定场数推定完成。真实列表完全为空但没有可确认的空态文字时，保守停止，不声称已经清空。

复用原生战斗的助战、编辑器/Chaldea队伍、高级策略、跳过剧情、茶壶和羁绊满停止。吃苹果沿用基础选项，默认金苹果，可切换“不食用”或其他类型。“自动处理编队限制情况”默认开启：限制关沿用游戏编队和默认战斗逻辑，下一小关恢复用户配置；关闭后遇到限制会保留现场停止。关闭“跳过剧情”时尊重正常剧情播放；需要手动推进的剧情、未适配的强制选择或等待超时会保留画面停止。

### 现有导航规则

- 从列表或故事舞台启动时，首次扫描先拉回顶部；战斗或纯剧情完成、确认返回幕间界面后，下一次直接扫描返回位置，不重复下拉确认。从助战或编队页启动也先完成当前小关，结算后再直接扫描。此优化同时用于总列表和地图列表；新进入故事舞台、扫描空地图后切回总列表仍执行首次复位。当前页没有目标时继续原有逐页扫描和触底复核。
- 总列表以右上“幕间物语”前景标题及左上“关闭”共同确认。奖励、剧情和限制弹窗优先于背景列表。
- 地图优先识别左侧“前往幕间物语”；同地图挑战其他幕间导致该按钮消失时，改由左上“关闭”图片、右侧同一棕色卡的Interlude/AP共同确认，并排除幕间总列表。关闭图片复用国日服各自的`后退按钮.png`，不额外检测关闭按钮亮度，仅用于识别，不点击。已完成/锁定幕间也能作为地图证据；清完或滚动后只剩绿色Free时，要求识别自由关卡文字，继续按原流程复位及遍历，不选择Free。地图确认同时用于任务入口、战后结算及下一关扫描。
- 对右侧棕色卡片逐行读取，联合卡片亮度、任务文字及锁定条件判断可挑战状态，不凭“新！”或位置判断。临时“开放条件缓和中”文字不能误判为未开启；暗棕色无字候选判为不确定。
- 地图只接受同一卡片内的Interlude和AP，拒绝绿色自由关卡及已完成行。地图没有主线NEXT标记，不能直接套用主线定位器。英文标记另有小范围OCR，容忍国服字距造成的拆分。
- 固定滑动、点击和等待放在Pipeline。总列表最多400次、地图列表最多12次单步复位/扫描，每步重拍，触底后再复核稳定帧；找不到候选不等于已完成。地图只有正向确认Free/完成/锁定证据且没有不确定行时才能判定当前页无目标，外层仍须复位遍历。
- 只有确认战后返回地图/列表或纯剧情完成后才计数。未知画面、定位失败和超时停止并保留现场，不执行通用回主界面恢复。
- 完整扫描地图确认没有可挑战幕间、没有不确定条目，且“前往幕间物语”缺失时，调用共享“回主界面”，复核主界面后查找迦勒底之门、确认门页面、查找幕间物语页签。两层入口列表都先归位，再使用有上限的JumpBack查找，单层最多20次下滑。点击和下滑均要求对应页面特征仍成立，最终必须确认幕间总列表，重新从顶部扫描。导航不计小关，保留累计完成数、次数上限及队伍/助战配置。
- 同一完成计数下最多执行一次回主界面重进，防止无进度往返；取得新小关进度后可以再次重进。新进入故事舞台却没有可挑战幕间时，有专属返回入口仍按原逻辑停止；缺入口时允许上述一次恢复。未知画面、扫描不确定、战败、结算超时及达到次数上限不触发该导航。任一导航阶段失败分别提示原因和手动打开列表的步骤，保留现场。

## 实现入口

`agent/custom/interlude_action.py`中的`InterludeRunner`复用主线单场战斗、助战及限制编队处理，导航与计数独立；`interlude_recognition.py`负责逐行候选及状态报告。固定动作与识别参数在`assets/resource/base/pipeline/自动幕间副本.json`，任务和选项在`assets/tasks/自动幕间副本.json`、`assets/options/自动幕间副本.json`。已接入interface与Agent注册，不更改自动推主线的选项。

非显然实机约束也写在相关Pipeline的`doc`：列表触顶650ms仍存在25至64px弹性回弹，原实测2400ms后恢复稳定。2026-11-13将总列表及地图列表的复位等待各增加1000ms，现为Pipeline等待3400ms加外层600ms，每次下拉后约4秒再截图比较；向后翻页的等待保持2400ms加外层600ms。棕色地图背景可能与卡片色带粘连，须先定位亮色卡头；地图返回按钮须有前景白底，避免奖励遮罩后的背景文字误命中。内联OCR均有全局唯一`sub_name`。
