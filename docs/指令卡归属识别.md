# 原生战斗的英灵与指令卡识别

规范依据：[MaaFramework Pipeline](https://maafw.com/docs/3.1-PipelineProtocol/)、[Custom & Agent](https://maafw.com/docs/1.3-Custom%26Agent/)、[ProjectInterface V2](https://maafw.com/docs/3.3-ProjectInterfaceV2/)。进本、技能点击、选卡与结算沿用原生自动战斗 pipeline，识别节点和图片资源统一放在 base。

原生战斗使用现有的 Chaldea 队伍配置读取攻略中的技能、出卡和敌方目标，不新增手动选怪、主输出或选卡倾向选项。

## 身份、技能与选卡流程

1. 进本时复用六槽初始编队快照。现有整幅头像匹配失败时，再尝试局部头像匹配。Chaldea 队伍提供另一份身份来源；同一位置两份证据冲突时保留未知。
2. 战斗主界面匹配当前三个位置的 HUD 头像，只搜索已确认的编队成员（含候补）。先确认从者存在，再识别其三个技能的 CD；未知位置按空位处理，不识别或使用该位置的从者技能。
3. 每次主界面观测更新当前前排，显式换人后同步阵容映射。HUD 头像匹配缓存已确认区域，画面变化时重新识别。
4. 点击 Attack 后由 `战斗_选卡展开等待` 等待上排宝具卡展开，再读取五张面卡、三处宝具区域及限制状态。
5. 面卡与宝具使用专用 command portrait，候选仅为当前前排身份的全部灵基和灵衣变体。缺少模板、同 ID 双前排、低分或候选分差不足时保留未知归属。
6. 优先执行 Chaldea 攻略中的出卡意图。未指定或缺失的面卡沿用原有通用补卡，优先选择可攻击面卡，再按既有卡色评分排序。

Chaldea 计划保留攻击记录中的英灵、卡色、敌方目标及面卡与宝具的混合顺序。敌方目标从 `options.enemyTarget` 转换为原生槽位，没有手动配置覆盖层。例如攻略的 `B → 宝具 → B` 会映射到当前截图中的真实位置。计划缺少的面卡或不可用宝具由普通面卡策略补齐，不重复选择同一张卡。攻略的 `card` 是英灵牌组索引，不是屏幕位置；同英灵同色面卡目前按画面从左到右匹配，不区分指令纹章或暴击率。攻略回合结束后恢复通用选卡。

## 宝具与封印

宝具是否可选由上排实际卡面及限制标记决定，**不读取 NP 百分比，不使用 NP 数值 OCR 判断可用性**。`NpCard.percent` 仅保留为历史快照的兼容字段。

- 头像确认失败时，需同时识别宝具名称和公共卡框；场景文字不能单独生成宝具卡。
- 被封印或无法行动的宝具不选择。
- 失效面卡优先避开；可攻击牌不足三张时，允许选择失效面卡占位以推进回合。

面卡头像使用 `TM_CCORR_NORMED`，门槛为分数 0.86、候选分差 0.05。宝具头像使用 `TM_CCOEFF_NORMED`、半分辨率及两段脸部区域，门槛为分数 0.80、候选分差 0.05，以减轻状态图标遮挡和明亮背景的干扰。匹配分数不是正确率。

## 离线资源维护

运行时不联网下载头像。资源来自 Atlas Academy 的 `NiceServant.extraAssets`：

| 资源目录 | 数据字段 | 用途 |
|---|---|---|
| `assets/resource/base/image/CommandCards/<servant_id>/` | `commands` | 面卡和宝具头像 |
| `assets/resource/base/image/ServantStatus/<servant_id>/` | `status` | 战斗 HUD 头像 |
| `assets/resource/base/image/battle/card_state/` | 游戏 UI 模板 | 封印、无法行动和宝具卡框 |

前两类各含 1562 张 PNG；`manifest` 记录来源 URL 和 SHA-256。维护清单不使用 `.json` 扩展名，避免被资源加载器当作 pipeline。限制状态模板的来源和修改见同目录 `SOURCE.txt`。

```shell
python tools/update_command_card_assets.py
python tools/update_command_card_assets.py --family status
python tools/update_command_card_assets.py --servant-id 2300900
```

默认按本地 `agent/custom/servant_list.json` 从 Atlas JP 导出更新，也可指定区域。目录中未取得专用资源的特殊 ID 保持未知，不借用其他英灵的图片。

## 验证与边界

开发期间已在幕间、强化本、日常本和月光矿区验证原生连续作战。最终版本使用 Chaldea 46199 在月光矿区连续三战，均完成战斗与结算，每场两回合；30 张面卡和 6 张宝具给出了正确身份，实际选卡顺序符合攻略，未调用 NP 数值 OCR。

该轮六次选卡观测的整体感知中位数约 2.46 秒，其中面卡归属约 0.99 秒、宝具归属约 1.14 秒；HUD 身份首次约 588 毫秒，缓存后中位数约 9 毫秒。这些是本机样本，不代表所有阵容和设备的耗时或正确率。

单人 NPC 等特殊布局可能无法得到初始身份，此时跳过未知位置技能并使用通用选卡。最终月光矿区一轮没有实机触发换人或三色封印，这两项仅有离线覆盖。已有失败续关页的识别遗漏另行记录，不在本次选卡改动范围内。
