### Chaldea 格式依据

固定对照 [Chaldea e656fa4b3e23228805efdec851358e0ab319aeeb](https://github.com/chaldea-center/chaldea/tree/e656fa4b3e23228805efdec851358e0ab319aeeb) 的模型、生成序列化器及色卡转换器。`tests/fixtures/battle_editor` 保存匿名字段样例、来源 URL 与 SHA-256。样例经 HTTP 正式保存、读取、草稿恢复和单字段修改后保持原树，包含 3+3 槽位、空值、御主、换人、整数三色、宝具及动作选项。

此项是官方源码字段与样例核验，未运行官方 Dart 程序，也未验证 Chaldea App 直接选择原始 JSON 文件。当前交付目标是与工程现有 Chaldea 战斗文件相同结构、相同保存位置并能供其消费。

检查真实缓存时发现龙之炉心等技能会使面卡颜色与基础牌组不同。校验现在保留合法索引与原始 `cardType`，将此情况报告为需要核对的改色警告；不会当作格式错误阻止保存。匿名“换人→技能改色→混合出卡”样例覆盖此边界，越界索引与重复同牌/宝具仍阻断。浏览器也已验证显式选择真实牌组卡、改色警告及撤销还原，当前表单不会静默编造改色索引。
