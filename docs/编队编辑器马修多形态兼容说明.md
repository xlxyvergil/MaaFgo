# 马修多形态与 Chaldea 兼容

在“选择从者”中点击玛修·基列莱特，会继续打开形态选择窗口。每项同时列出星级、COST、三个技能和宝具，点击即加入编队；关闭窗口不改变原成员。已选马修可在成员属性区点击“切换马修形态”，等级、技能等级、礼装及未知字段保留，修改可撤销。普通从者选择流程保持一致。

六组均使用 `svtId=800100`。历史强化阶段由显式技能和宝具 ID 表达，不依靠灵衣号猜测。帕拉丁的 Buster 宝具 `800108` 仍作为合法宝具变体保留；本窗口设置常规 Arts 宝具 `800107`，不模拟游戏中的圣剑装填条件。

导入支持 Chaldea 使用的灵衣小号和完整战斗形象编号：

- 普通组：`11/800130`、`14/800160`、`15/800170`，均为四星、0 COST。
- 奥特瑙斯组：`12/800140`、`13/800150`、`18/800151`，均为四星、0 COST。
- 帕拉丁组：`17/800190`、`19/800200`、`20/800210`，均为五星、16 COST，包含水着 Ver.03。
- 常规灵基 `0–2` 为三星，`3–4` 为四星。未写或设为 `null` 的 `limitCount` 按 Chaldea 的默认值 `4` 解释。

## 导入与实际执行

形态显示是只读投影，导入时不新增或重写字段。已填写的 `skillIds`、`tdId` 优先；缺失的技能／宝具仅使用预览回退，不冒充原方案中已指定的要求。奥特瑙斯若没有足够明确的历史字段，预览使用修复后的组合。未知灵衣号保留原值，COST 标为未确定，可用“切换马修形态”重新选择。

保存仍为现有 Chaldea 对象，不新增编辑器专用的从者身份或形态字段。草稿、保真 JSON、一图流回导均保留标准字段和未知数据；星级、COST、技能图标及宝具预览随配置解析。

自动编队、助战与战斗 HUD／面卡识别继续使用同一个马修身份及工程已登记的整组外观模板，不通过形态字段限制识别。原生战斗按前排槽位和技能序号执行，不要求识别画面上的技能名称。不同形态仍属于同一位自有从者，不能绕过重复自有从者检查。编辑器选择形态不会在游戏内切换灵衣、完成强化或调整培养状态，请在游戏内确认准备使用的技能和宝具。
