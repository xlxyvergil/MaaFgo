## 按血条推进的五行计划

```json
"phasePlanTurns": [[1], [2, 3], [4], [5]]
```

四组对应弓、杀、骑、术四条血，数字是编辑器方案行，不是固定游戏TURN。敌人职阶用于确认血条；宝具、颜色或可靠补牌不足时，同一行可以额外打回合。首次计划技能只安排一次，进入下一血条后不会补放旧阶段未消费的行，日志会记录跳过的行。

| 血条／方案行 | 首次固定技能 | 固定宝具与普通卡空位 |
|---|---|---|
| 弓／1 | 莉莉丝1→所长1→妖兰1→2→3 | 所长B全体宝具→妖兰B全体宝具→auto |
| 杀／2 | 御主3将前排1妖兰与后排第一位术呆换人，术呆1 | 术呆宝具→auto→auto，优先累计两次蓝攻击 |
| 杀／3 | 所长2→3，莉莉丝3，术呆3给自己 | 莉莉丝Q宝具→auto→auto；蓝攻击或合法补牌未足时暂扣攻击宝具 |
| 骑／4 | 术呆2给莉莉丝、御主2给莉莉丝、御主1给当前前排3 | 术呆宝具→莉莉丝宝具→auto，绿色尚缺时优先真实绿攻击 |
| 术／5 | 莉莉丝1→2；冷却未好时可能跳过 | 当回合术呆宝具先弱解→莉莉丝宝具→auto |

御主1在本御主服是1500治疗与10星，**不提供攻击力提升**；正常前排3是所长。该治疗没有绑定所长实例，不会因所长已经退场而重放一个不存在的从者技能。末条没有固定所长1，避免第七场那种旧actor已退场的硬停止。

换人后前排是术呆／莉莉丝／所长，妖兰在后排。术呆动作仍绑定初始第4位，莉莉丝初始第2位，所长初始第3位；当前前排目标则按换人后的实际位置填写。

**莉莉丝2并不是严格留到末条。** 虽然固定行把它放在行5，重复技能名单也包含莉莉丝；骑条等牌时若它已可用，续航会提前释放。第八场实际T5骑条动态用了莉莉丝1和2。这是当前脚本的真实行为，不能只看固定行号推定技能尚未使用。

所长满破万华镜用于首行启动并保留2技能；行3仍需在所长2后满足游戏内3技能的NP条件。所长3不会自动补放，只有显式行安排。所长宝具4000101的实际卡色是B，正式 `npMetadata` 和通用颜色表均写B；第一条第一张的 `explicit_preparation` 许可不预测伤害，也不保证所长不会抢破条。

## 等待、续航与辅助尾卡

每行最多额外普攻等待8回合，整场最多40回合。重复行会根据真实CD给名单内的莉莉丝、术呆、所长补放可用技能，默认目标自己；身份或CD不可靠时跳过，所长3始终不自动补放。首次固定技能如果被游戏以冷却等原因拒绝，不等于该技能已经生效。

`chargePriorityServantIds` 依次偏向术呆、莉莉丝的蓝卡；本组三牌不会消耗的已就绪宝具取消蓄能偏好。固定宝具不可用时，也会优先给其可靠身份或显式actor蓄能，不把封印断言为NP不足。

`useCleanseNpWhileWaiting:false` 保留固定术呆宝具给完整计划链，避免等莉莉丝或面卡时先用掉，下一回合又要求同一张宝具而反复回充。代价是等牌回合少一层术呆宝具保护。末条仍要求**当回合**术呆先弱解，不推测上一回合弱解、弱化无效或自然到期能代替本回合检查。

`finisherFacePhases:[2]` 只在杀条限制主攻宝具同组的普通卡为术／AE。骑、术条允许其他职阶的辅助尾卡，以减少等待合法AE面卡。**如果莉莉丝宝具没能破条，辅助尾卡可能抢破条，使本场缺少指定击破职阶的任务。** 脚本不预测HP和暴击伤害，应按实测确认归属，必要时通过另一场胜利补任务。

第八场骑条使用术呆宝具→莉莉丝宝具→术呆A，莉莉丝宝具动画内已经Overgauge，术呆A之后才出手；末条同一恢复链中，莉莉丝宝具内已经Overkill并敌0，术呆A未出手。因此这两次实际归属有连续帧支持，不能推广为任意伤害或任意尾卡都安全。

全程禁止完整B/A/Q三色链，包含宝具颜色。120版只对“阶段方案有明确auto位、正常候选只能形成Mighty”的情况转入有界安全普攻等待；三张固定Mighty、身份或职阶错误、最终输入守卫仍停止。等待不插入攻击宝具，末条等待不选AE面卡。第八场恢复是直接放开辅助尾卡找到A-Q-A收尾，**没有在设备上走这条新等待分支**；该分支目前有真实手牌模型回放与单元测试，实机覆盖另记。
