### 视频发牌与自动补牌边界

T1需要所长红＋枪红，T2需要AE蓝，T3需要AE绿并且枪宝具已回收。固定脚本按计划回合执行，不会根据实际Break自动移动下一回合技能，也不会因为指定牌没发到而等待。

当前执行器在指定面卡缺失或宝具未就绪时，会用普通卡补该位置。这可以继续战斗，但不保证色卡次数、职阶破条或4T伤害达标。该方案关闭开局等牌；现有等待只能检查开局目标从者的颜色，无法保证后三回合的特定牌。

全局高级策略已写入：**平衡、不等关键牌、关闭方案结束后自动补从者技能、回合上限40**，补牌偏向AE并记录宝具颜色。固定技能/宝具/面卡先执行，策略只处理剩余普通卡。若T4未击杀，后续通用出卡不会自动修复焦热、已过期buff和任务计数，需要编辑计划再尝试。

```json
  "remainingColorAttacks": 2,
  "requireCleanseBeforeFinish": true,
  "finalBarPreparationTurns": [5]

```

`phase` 是本次启动时的血条，1～4分别对应画面的 `ARCHER`、`ASSASSIN`、`RIDER`、`CASTER`，不是游戏回合。前三条 `remainingColorAttacks` 为尚需完成的红、蓝、绿攻击次数，范围0～2；末条填0。策略从当前同帧截图识别敌人职阶，未知或进度不连续时停止。只有实际提交三张且攻击动画结束后才累计颜色，术呆辅助宝具不计蓝攻击。

固定宝具未就绪时会保留现场停止，不用普通牌替代；固定出卡位置保留，空位才补牌。颜色不足时倾向用较低风险的普通牌积累次数，但没有血量与暴击伤害预测，不能保证普攻不会提前破条。`requireCleanseBeforeFinish:true` 要求末条先使用可用的术呆宝具，不会推测焦热已失效或被抵抗。
