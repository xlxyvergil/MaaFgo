## 使用方法

1. 在编辑器方案库打开上述文件，按自己的从者和礼装修改并保存。视频的高练度照实记录，不表示最低练度要求。
2. 地狱的试炼任务的队伍方案填写 `地狱的试炼_202611_天魔轰临_枪AE双核.json`；高级策略选择 **使用编辑器/chaldea配置**。
3. 开战前检查冠位枪盘、礼装、所长战斗形态和御主服。自有冠位从者的礼装当前不会由自动编队修改，须自行装备；助战筛选如果没有对应礼装识别资源，可先手动选好符合要求的好友冠位AE。
4. 从助战/编队界面开始新战斗。此文件没有中途续跑游标，不能在游戏第2回合直接启动并期待自动接上计划第2回合。
5. 结算后查看任务列表；缺少色卡次数等任务时，可编辑出卡或分次通关补齐。数据通过校验不等于任务达成。

“重复挑战次数”默认1，范围1～999。每次通关后回到活动页，再重新选助战与进本；达到次数后停在活动页。战败、流程失败或手动停止不会继续下一场，任务完成情况仍以15项列表为准。

## 必要机制

- **冠位枪盘第12格**：盘 `10003`、技能 `5048000`「一刺にて城を穿つ（槍）」提供宝具伤害前解除敌方防御强化。第一条血必须在破血前清掉信长全部可解除防御提升；只勾选冠位不会替用户点亮盘子。配置的 `grandClassBoardSquares:[12]` 只记录已确认必要格。
- **所长第三形态**：第三形态3技能才能给全队3回合弱化无效。JSON记录不会替用户切换游戏中的战斗形象，须在游戏中固定第三阶段。
- **术呆宝具解焦热**：所长T2的弱化无效覆盖T2–T4，但不会清除T1已中的焦热；T2术呆宝具用于清掉既存弱化。第四条击杀者必须没有焦热。
- **AE3保留到T4**：提供充能和增伤，同时附加3回合后无视毅力即死；不能随意提前，也不能把未击杀后的续打视为无限安全。

从者与冠位盘已用 [Atlas日服从者数据](https://api.atlasacademy.io/nice/JP/servant/1002200)、[所长数据](https://api.atlasacademy.io/nice/JP/servant/4000100)和[冠位盘导出](https://api.atlasacademy.io/export/JP/nice_class_board.json)交叉核对。原始响应及来源哈希保存在本地分析目录。

## 发牌与自动补牌边界

T1需要所长红＋枪红，T2需要AE蓝，T3需要AE绿并且枪宝具已回收。固定脚本按计划回合执行，不会根据实际Break自动移动下一回合技能，也不会因为指定牌没发到而等待。

当前执行器在指定面卡缺失或宝具未就绪时，会用普通卡补该位置。这可以继续战斗，但不保证色卡次数、职阶破条或4T伤害达标。该方案关闭开局等牌；现有等待只能检查开局目标从者的颜色，无法保证后三回合的特定牌。

全局高级策略已写入：**平衡、不等关键牌、关闭方案结束后自动补从者技能、回合上限40**，补牌偏向AE并记录宝具颜色。固定技能/宝具/面卡先执行，策略只处理剩余普通卡。若T4未击杀，后续通用出卡不会自动修复焦热、已过期buff和任务计数，需要编辑计划再尝试。
