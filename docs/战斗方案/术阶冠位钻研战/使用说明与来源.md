## 配置要求

- **01**：自有100级宝5陈宫、80级宝5术闪；借100级宝1冠位孔明。二星主C仍需圣杯、附加和冠位树。
- **02**：自有100级宝1不夜术、80级宝2术闪；借100级宝1冠位孔明。不夜术原作金芙芙2000。
- **03**：自有100级宝1梣、80级宝1喀耳刻；借120级宝5梣。原作第一张先用自有梣的红卡，再使用双梣宝具。
- **04**：自有100级宝1冠位孔明，借100级宝5普勒拉蒂；第三张指定孔明蓝卡。普勒拉蒂1技能选不更换灵基，保留原作形态。
- **05**：自有100级宝2不夜术、80级宝5海伦娜；借100级宝3冠位术呆。相对低配不等于零抽卡或低宝具海伦娜也可代入。
- **06**：自有与助战均100级宝2冠位梣，搭配65级莎士比亚和80级宝1喀耳刻；自有梣金芙芙2000，使用换人。
- **07**：自有120级宝5伊莉雅、100级宝1孔明；借120级宝5梣。两名冠位输出均金芙芙2000、五附加10；保留梣红卡补刀。
- **08**：自有120级宝5冠位有珠、90级宝1斯卡蒂；借100级宝1冠位斯卡蒂。T1指定自有斯卡蒂两张绿卡；T2斯卡蒂宝具后接有珠宝具。
- **09**：自有100级宝5梣，借120级宝5梣；搭配70级宝5阿维斯布隆。两位梣保留原作高等级礼装、NP50羁绊与冠位树要求。
- **10**：自有120级宝5陈宫、80级宝1术闪；借100级宝5由井正雪。陈宫金芙芙2000，以高练度和高宝助战归为高配。

## 调用与图片

1. 本批JSON已新增到开发版与本机打包版的 `config/Battle`。其他客户端可将所需JSON复制到它的 `config/Battle`。
2. 战斗任务选择 **Chaldea队伍导入**，填写完整文件名；战斗方式使用 **原生自动战斗**，助战方式选择 **使用编辑器/Chaldea配置**。
3. 也可在编辑器“从 config/Battle 选择”中打开。`一图流/` 下是对应PNG原图，保留底部回导标记可以通过图片导入还原完整方案。
4. 开始前在游戏内核对冠位三槽礼装、羁绊NP50/初始效果、从者强化、附加技能、金芙芙、卡强化、御主服等级与天赋树。当前自动编队不会调整冠位从者礼装，必须手动预先装备。
5. 使用原作指定手牌的03、04、07、08，缺牌时不能保证原作回合数；NP不可用或缺指定卡时执行器会用普通卡补齐。原计划结束后恢复通用自动战斗。

## 转换与兼容说明

- 阵容、唯一助战、从者/礼装/技能/宝具/附加/冠位树要求保留原站配置；没有擅自降低原作要求。
- 原站对自身与全体技能也记录了当前选中的队友及敌人。本批按精确技能元数据清理无选人弹窗的冗余目标；真实单体技能的目标保留，避免实战误点。
- 本关敌方deckId是1和3，中间槽空。原作enemyTarget=0对应所罗门、原生敌方3；enemyTarget=2对应ロード・ログレス、原生敌方1。保留单体敌方技能和攻击的选敌；没有套用上次单Boss关卡的处理方式。
- 原站普遍携带 `actWeightSelections=[-1,...]`。已查阅 Chaldea 官方执行器：-1是跳过带权随机效果的模拟回放记录，不是游戏里的按钮。只将全部为-1的记录移到 `_guideNotes.originalSimulationDelegate`，不会忽略真实选项或非负分支。实际游戏仍会发生随机效果，无法强制跳过。
- 仿真random/threshold及顶层仿真参数保留在来源备注，原始JSON和哈希另作本地证据保留。MaaFGO不会按模拟器指定数值控制暴击或伤害随机。
- 为技能与宝具/面卡添加初始成员实例绑定，换人后仍对应真实成员，双梣与双斯卡蒂不会混成一个实例。
- **04普勒拉蒂**保留 `skillActSelectSelections=[0]`，1技能选择“不更换灵基”。已验证原生特殊技能选择队列能读取该值。
- **01、10陈宫**的宝具均位于最后，牺牲最左侧队友后没有再安排该队友动作；没有凭空插入主动退场操作。
- **03**先用自有梣红卡再开双宝具；**04**第三张指定孔明蓝卡；**07**保留助战梣红卡补刀；**08**T1需要自有斯卡蒂两张绿卡，属于手牌条件2T。
