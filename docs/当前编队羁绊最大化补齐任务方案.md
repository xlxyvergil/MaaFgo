# 当前编队羁绊最大化补齐任务方案

## 1. 目标与边界

新增独立任务“自动补齐从者礼装（按照羁绊最大化）”。任务不读取 Chaldea 队伍，
而是识别玩家当前已经编好的队伍，在 COST 上限内补齐空从者位并配置常驻羁绊礼装。

- 只允许从编队确认页启动。
- 已有自有从者始终保留，不提供替换已有从者的选项。
- 只有真正的空从者位才会补入从者，最多保持 5 名自有从者。
- 助战从者和助战礼装不识别身份、不计分、不编辑。
- “是否支持修改所有礼装”默认关闭。关闭时只填空礼装位；开启时，所有自有从者
  已装备的礼装都允许先卸下，再按羁绊最大化重新配置。

## 2. 选项

| 选项 | 默认值 | 作用 |
| --- | --- | --- |
| 补齐从者优先星级 | 5 星 | 只控制空从者位的查找顺序，无匹配时按 5→0 星回退。 |
| 羁绊基础值 | 1200 | 比较百分比与固定值羁绊效果。 |
| 使用本地从者库 | 否 | 有效时直接使用 `player_servants.json` 规划，否则实时扫描。 |
| 使用本地礼装库 | 否 | 有效时只使用 `player_equips.json` 中的礼装，否则实时预检。 |
| 是否支持修改所有礼装 | 否 | 否：锁定已有礼装；是：所有自有从者礼装均可重新配置。 |

## 3. 当前编队识别

进入配置页后等待连续两帧槽位状态一致，再完成以下识别：

1. 使用灰度空槽特征区分空从者位。
2. 使用助战标记识别并排除助战槽。
3. 对其余槽位，使用全部从者编队头像模板匹配具体从者。为避免“5个槽位 × 全库模板”
   逐张滑窗导致 CustomAction 超时，利用编队卡固定布局，在内存中截取 NarrowFigures
   的稳定位置，将槽位与模板统一缩放为 48×48 灰度特征并用矩阵一次计算相关性；
   最高分必须不低于 0.80，且与第二候选分差不低于 0.20，否则在修改前安全退出。
4. 对每个自有从者礼装位依次分类：已识别羁绊礼装、空礼装位、未知占用礼装位。
   普通礼装不需要识别具体名称；关闭全礼装修改时用截图锁定，开启时允许卸下。
5. COST 必须连续识别两次且结果一致。

识别结果形成当前队伍基线，包括从者 ID、槽位、羁绊特性、已识别羁绊礼装、空槽、
未知占用槽和当前 COST。

## 4. 优化与执行

已有从者作为固定成员参与羁绊计算。空从者位调用现有星级筛选、玩家库存扫描、候选排序、
礼装联合预检和 COST 回退逻辑。新增从者成功落位后，其礼装位加入可补齐集合。

关闭“修改所有礼装”时：

- 已有礼装全部锁定；已识别羁绊礼装纳入基线和最终评分。
- 未识别普通礼装保留，其 COST 已包含在游戏显示的当前 COST 中。
- 只对确认的空礼装位调用羁绊礼装优化。

开启“修改所有礼装”时：

- 在完成全队识别和基线评分后，卸下全部自有从者礼装。
- 在释放后的 COST 空间内，最多选择 5 张不重复的常驻羁绊礼装。
- 礼装缺失、定位失败或实测 COST 异常时，复用现有黑名单和重新规划逻辑。

## 5. 代码复用与隔离

新 Action 继承 `CompleteBondFormation`。新脚本只维护任务选项解析、确认页限制、当前队伍
识别和执行编排，以下能力直接复用既有实现：

- 从者与礼装数据库、本地库存加载；
- 羁绊计算、从者排序和礼装组合优化；
- 从者仓库扫描与最终定位；
- 礼装库存预检、缺失重规划和唯一性；
- COST OCR、逐次实测和超限回退；
- 礼装空槽判断、卸装、最终模板复核和失败恢复；
- 已验证的 `羁绊补齐-*` 固定界面 Pipeline。

旧 `complete_bond_formation` Action、Chaldea 任务入口及其选项不改变。新任务使用独立
CustomAction 注册名、任务 JSON、选项 JSON 和入口 Pipeline；Agent 只新增一条模块导入。

## 6. 成功与失败条件

提交编队前必须满足：

- 原有从者与助战槽复核通过；
- 锁定礼装与初始截图一致；
- 新增从者和礼装模板复核通过；
- 最终 COST 稳定且不超过上限；
- 最终已知羁绊值不低于初始基线。

任一步骤在提交前失败，均退出选择页并取消配置变更，恢复任务开始前的已保存编队。由于
任务只允许从编队确认页启动，不会丢弃玩家进入任务前尚未保存的手工编辑。

## 7. 验证范围

- 1～5 名自有从者与不同空槽位置；
- 助战位于前排或后排；
- 空礼装、羁绊礼装和普通未知礼装混合；
- 修改所有礼装开关的两种状态；
- 本地从者/礼装库分别启用、同时启用和无效回退；
- COST 临界值、礼装缺失、识别不唯一和失败恢复；
- 原 Chaldea 自动编队及其羁绊补齐功能回归。
