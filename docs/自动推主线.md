# 自动推主线：设计与实施记录

## 目标与范围

从当前主线地图或已打开的副本列表开始，连续推进普通主线战斗和可跳过的纯剧情关卡。新增独立调度入口，不进入通用战斗调度，不回迦勒底主界面，不使用连续出击刷同一关。

每轮优先级固定为：**副本列表已打开 → 当前地图可见 NEXT → 确认地图后轮巡寻找 NEXT**。点击地图节点后必须确认列表打开；每关结束后重新判断位置。

普通助战、NPC 助战、编队、原生战斗和 BBC 单场执行复用工程已有实现。特殊章节解谜、大奥、选项分支、锁定关卡、跨章节导航不在首版自动处理范围；无法继续时说明原因并停止，不把“找不到目标”当成“主线已完成”。

## BBC 核对结果

只读分析本地已提取的 `FGObattle.pyc`，单独反编译 `dealMainStory` 和 `gotoNextOne`，未运行 BBC 程序。

- `dealMainStory` 使用 NEXT 原图与二值遮罩；地图匹配支持 0.4～2.3 的尺度范围、步长 0.05。
- `gotoNextOne` 使用彩色 `TM_SQDIFF_NORMED`，差异阈值 0.2；先寻找地图 NEXT，再确认关卡区域，随后在副本列表再次寻找 NEXT。
- 地图点击在匹配中心下方，1920 基准偏移 150，并随地图缩放调整；列表点击偏移 100。实现必须按 1280×720 换算，并验证点击后状态。
- `reddot` 在该初始化中名为 `daaoreddot`，属于大奥处理，普通主线首版不导入。
- 反编译部分复杂分支可能失真；只参考已核实的模板、算法、数值及两阶段识别思路，不照搬异常控制流。

## 结构

1. `assets/tasks/自动推主线.json`：独立任务，默认原生战斗，支持 BBC 单场交接。
2. `assets/options/自动推主线.json`：推进关卡上限、战斗方式；复用原生助战、Chaldea 编队、苹果选项。
3. `assets/resource/base/pipeline/自动推主线.json`：识别节点、必要动作、入口和状态提示。
4. `agent/custom/main_story_action.py`：有界外层循环，管理状态、计数、超时、停止和单场交接。
5. `agent/custom/main_story_recognition.py`：NEXT 遮罩多尺度匹配，返回可点击点和匹配证据；不依赖 BBC 程序运行。

外层使用克隆 Context，局部配置 BBC 单场次数与模式、编队会话及必要出口，不修改通用调度。地图轮巡复用现有蛇形滑动节点的动作，拆开初始化的重复滑动，每滑一次重新识别；不直接调用带活动 OCR 目标的整个轮巡。

## 状态与交接

- **寻找关卡**：副本列表优先；有列表但无 NEXT 时有限次上下翻查，仍无目标才返回地图。本轮已查空的地图点不得无限重进。
- **地图导航**：菜单与地图专用控件确认地图；当前画面先找 NEXT，仅 miss 后遍历。未知画面不滑动。
- **打开列表**：点击 NEXT 对应地图点，限定重试次数，等待正向列表证据。
- **进入关卡**：列表中以 NEXT 选择待推进关卡，禁止退化为“上次执行”或任意第一关。处理 AP、剧情、任务开始提示；区分点击未生效与真正离开列表。
- **单场原生战斗**：每场初始化编队会话、重置有限节点计数；复用 `进本流程` → `原生自动战斗入口`。确认进入战斗后才计为战斗。
- **单场 BBC**：复用 `bbc战斗`，限定 `run_count=1`、普通模式；不给 BBC 主线地图导航权。BBC 返回后由外层确认结算状态。
- **纯剧情**：离开原列表并处理剧情，重新出现地图/列表后计一次推进，不等待不存在的助战，不增加战斗次数。
- **结算**：复用下一步、好友申请关闭、奖励关闭、跳过剧情动作；出现地图/列表就结束本场。识别失败/撤退则停止，禁止用 run_task 成功推断作战胜利。
- **停止**：推进上限、用户停止、AP 无法补充、遍历无目标、战败、未知状态超时；结果分别报告已推进关卡数与完成战斗数。

### 当前使用方式

选择国服或日服资源包，在“战斗相关”中运行“自动推主线（bata）”。可从当前主线地图或已打开的副本选择界面开始；默认上限 10 关，可改为 1～999。战斗关与纯剧情关分别记录，推进上限包含两者。首次使用建议设为 1 关验证。

默认原生战斗，沿用原生助战和 Chaldea 选项。BBC 模式需先启动 BBC；每次固定 `run_count=1`、`battle_type=0`，由 MaaFGO 负责重新导航。本模式复用现有 BBC 单场接口，返回画面尚需实机确认。补体力沿用“是否吃苹果”设置。首版自动跳过可识别剧情，没有暴露“不跳过”选项；需要选择对话选项、无法识别跳过按钮时超时停止。
