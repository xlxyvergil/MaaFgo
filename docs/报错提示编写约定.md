# 面向用户的报错提示

新增或修改报错时，优先按“发生了什么 → 为什么无法继续 → 用户该怎么处理”说明，让普通玩家可以根据提示完成处理。

- 使用简洁、易懂的中文，避免只给出错误码、内部字段名或“配置无效”等笼统结论。
- 给出具体可执行的处理步骤，准确引用当前界面的选项、输入框或按钮名称。涉及外部方案时，说明在哪里修改，以及是否需要重新导出、导入或重试。
- 不同原因分别提示，例如未开启配置、未填写方案、没有标记助战、标记多个助战，不能统一写成同一个模糊错误。
- 确有适用的替代方式时可简短说明，不擅自切换执行方式。
- 保留定位问题所需的名称、数量等信息。原因尚未确认时明确说明，不把推测写成确定结论，也不提供未经验证的解决方法。

例如，没有标记助战时：

> 导入的队伍没有标记助战，无法确定要借用哪位从者。请在 Chaldea 或编队编辑器中，将准备借用的一位从者标记为助战，重新导出并导入；也可将助战方式改为“自定义助战”，在 MAA 中设置要借用的从者。
