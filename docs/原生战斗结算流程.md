## 问题与处理（2026-10-31）

结算兜底会点击右上角推进；活动关返回地图时，该位置可能是活动报酬入口，误入报酬页后，原有地图／列表识别无法完成结算。

在原生最终场、连续场及其结算轮询中，保留奖励详情等明确弹窗的优先处理，再检测左上角关闭按钮；命中后不再盲点右上角，而是发送一次 ESC（复用 `主界面判断-返回` 的 Android 键值111），等待并确认回到既有地图／列表终点。复核失败时停止，不重复发送 ESC，也不恢复右上角点击。

复用 `后退按钮.png`，限定左上 `[0,0,230,100]`，阈值0.9，不新增截图模板。国服当前“歌姬点数报酬”截图初步模板得分0.9839；日服沿用 base 同名模板，实际画面匹配仍待验证。仅在战后结算链增加此分支，不以左上按钮直接推断战斗内胜利。

连续场返回地图后，由既有下一场“点击关卡→进本”流程继续；最终场返回后结束当前结算。未改战斗次数计算和胜败判定。

验证覆盖：最终／连续场均先退出报酬页，返回地图后成功；ESC后未返回时失败且不补点；原撤退、好友申请、连续出击及剧情分支保留。实机验证以当前国服报酬页为入口，目标仅返回地图，不开始新战斗。
