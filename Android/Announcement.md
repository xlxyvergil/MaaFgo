# MaaFGO 安卓测试版

请在 Android 10 及以上的 ARM64 手机或 x86_64 模拟器使用对应架构的安装包。先安装对应区服的 FGO，再选择 Shizuku 或 Root 授权。

Shizuku 无需 Root；Android 11 及以上可通过无线调试启动。已经 Root 的手机也可以直接使用 Root 模式。

后台画面固定为 1280×720。若模拟器的后台预览黑屏，请切换前台模式；前台要求游戏画面为横屏 16:9，推荐分辨率为 1280 × 720。选择区服、配置登录包名后，可先测试登录、种树，再测试单场原生战斗。

前台模式请先在首页点击“打开操作面板”，再点击屏幕边缘的悬浮球，从悬浮面板开始任务。

安卓版使用原生自动战斗，支持 Chaldea 队伍，不包含 BBC。首次测试建议只执行一场，并在应用内导出失败日志用于排查。

请授予通知权限并允许应用后台运行。任务启动时 Shizuku 或 Root 服务必须已连接。
